Learning-based control lets robots handle tasks that are hard to model by hand. Current student projects use reinforcement learning to pick up objects floating in liquids with a robot arm (starting with reward shaping for the reach phase), reinforcement learning for drone navigation during exploration, and world models for controlling humanoid robots.

Earlier, as part of the CNPq project *Apprentice: reinforcement learning for collaborative tasks in multi-agent systems* (2019–2023), we used reinforcement learning with mobile robots to locate gas sources in mining environments.
